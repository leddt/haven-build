# Crafting

I won’t go into detail past the first craftsman here, especially given that Bannerspear is a starting class. We should start with flexible slippers, as we’ll definitely want to pick up some extra loot. After that, we should pick up a spyglass if there’s one to spare so that we can get advantage an additional time each cycle. We don’t much care about our chestpiece; hide armor is very efficient for if we do get attacked, but tanking isn’t a priority, so only do that if we don’t need it for building.
