# Enhancements

We have some great options for enhancing our ranged attacks. If you want to use [Incendiary Throw](#_8o6bxqg6p44y), put \+1 on it to make it more likely we get the wounding effect. With this enhancement, Incendiary throw survives for quite a while in our hand whenever there are weak or shielded enemies around. After this, I would add poison to [Javelin](#_yjv3bbxgjo2l). It’s common that we’ll use this early in the rest cycle since we want the wind afterwards. [Driving Inspiration](#_yc7xrq7k6p0v) should get a \+1, as we want to use the advantaged attack to guarantee a kill. We can also increase movement on our granted moves; we usually don’t need much for ourself, but will have trouble having our banners keep up. One great option is to add wind to one our moves (such as [Combined Effort](#_bj30gaanrifd)) so that we have an additional option for an early element.
