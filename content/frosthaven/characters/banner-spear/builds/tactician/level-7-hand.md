Tri\-Thrust’s formation is an ambitious action, but we are more than happy to use the bottom instead as movement with some bonus attacks when necessary. We’ll delegate [Tip of the Spear](#_9biaxul0blo7) primarily as a formation and use Tri\-Thrust only when we think we can actually line it up on a key target. Either way, we have to cut another formation. [Resolved Courage](#_zgu5oklkgem7) is very impressive, but we have stun and disarm on backup if we need some CC, and we have a few additional quick initiatives with better movement options. We can bring [Resolved Courage](#_zgu5oklkgem7) if we need a lot of CC, another fast initiative, or if the scenario looks challenging, typically dropping [Pincer Movement](#_768ksnsz0b8i).
