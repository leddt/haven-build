Tri\-Thrust’s formation is an ambitious action, but we are more than happy to use the bottom instead as movement with some bonus attacks when necessary. We’ll delegate [Tip of the Spear](#tip-of-the-spear) primarily as a formation and use Tri\-Thrust only when we think we can actually line it up on a key target. Either way, we have to cut another formation. [Resolved Courage](#resolved-courage) is very impressive, but we have stun and disarm on backup if we need some CC, and we have a few additional quick initiatives with better movement options. We can bring [Resolved Courage](#resolved-courage) if we need a lot of CC, another fast initiative, or if the scenario looks challenging, typically dropping [Pincer Movement](#pincer-movement).
